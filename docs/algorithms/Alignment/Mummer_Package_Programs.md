# The other programs of the MUMmer 3.23 package

Audit items A3-9d / A3-9e / A3-9f (B09 F204 ...). Every program of `dpkg -L mummer` that is not part of the nucmer / delta toolchain (see [Nucmer_And_Delta_Programs.md](Nucmer_And_Delta_Programs.md)) is ported here and compared with the installed binary (Debian `mummer 3.23+dfsg-8`; the sources are the Debian source package `mummer_3.23+dfsg.orig.tar.xz` with its patches applied - `addition_from_mugsy.patch` (delta2blocks, delta2maf), `0009-improve-performance-of-delta2maf.patch`, `mummerplot.patch`, `gnuplot.patch`, `remove-csh-dependency.patch`). The oracle generators are in `scripts/alignment/`, the recorded runs are embedded test data (`TestData/Alignment/*.jsonl.gz`).

## `mummer` (A3-9e)

`MummerProgram.Run` is the `mummer` command (Kurtz' `maxmat3`, `src/kurtz/mm3src`: `maxmatopt.c` options, `maxmatinp.c` file reading, `procmaxmat.c` output, `findmaxmat.c` / `findmumcand.c` matching, `cleanMUMcand.c` the `-mum` filter). MCP tool `mummer`.

* **Input.** `scanmultiplefastafile`: every `>` outside a description starts a record (the first white-space delimited word of the header is its id; the line is otherwise ignored), residues are lower-cased, white space is dropped, the records are joined by one separator byte (255). Residues before the first `>` belong to the first record. A file without `>` ("no sequences") or without residues ("empty sequence"), and an empty file, abort the program. With `-n` every residue that is not `a c g t` becomes a replacement byte (252 in the reference, 251 in the query) that matches nothing; without `-n` all bytes are letters of the alphabet (so `mummer` also finds matches in protein text, which `promer` relies on).
* **Matches.** The program walks a suffix tree of the reference; for every query suffix `i` it reports the reference suffixes that share a prefix of at least `-l` characters with it and are left-maximal (`maxmatch`), or those whose longest match is unique in the reference (`mumreference`: the longest prefix of the query suffix that occurs in the reference ends inside a leaf edge, i.e. occurs exactly once; the terminator of the tree makes a match that touches the end of the reference unique like any other), and for `-mum` additionally the ones unique in the query (`mumuniqueinquery`: candidates sorted by reference start / descending length, those whose right end is not beyond the previous one are dropped). The port builds the suffix array of the joined reference with a terminator **greater than every byte**, which is the order the tree enumerates its leaves in (verified: sentinel low fails 69 of 300 random runs, sentinel high none), follows the suffix link of a suffix-array interval with the inverse array and the LCP array and narrows by binary search. `maxmatch` lists the occurrences of one query position in suffix order; `-mum` lists by reference position.
* **Output.** Per query record a header `> id` (` Reverse` for the reverse strand, `  Len = n` with `-L`), then `%8lu  %8lu  %8lu` (reference position, query position, length); several reference records (or `-F`) print `  id<padding>  %8lu  ` with the reference id padded to the longest header (including its terminating newline in the program's count) and the offset in the record. The reverse strand matches the Watson-Crick complement read backwards (`wccSequence`: IUPAC pairs `r/y m/k b/v d/h`, `s` `w` self, every other character becomes `n`, replacement bytes stay); `-c` prints `querylen - start` instead of `start + 1`. `-s` prints the matching text below each match.
* **Errors.** `-b` with `-r`, `-c` without `-b` / `-r`, `-l` not a positive integer, no query file, more than 32 query files, `-mum` with `-maxmatch` / `-mumreference` ... are errors of the program (`ArgumentException`); the file errors are `FormatException`.
* **Standard error.** `MummerTextOutput.Messages` holds the deterministic stderr lines (`# reading input file`, `# construct suffix tree`, `# matching query-file`); the three timing lines of the program (`# CONSTRUCTIONTIME`, `# COMPLETETIME`, `# SPACE`) are not reproduced.

**Oracle.** `scripts/alignment/generate_mummer_cli_oracle.py`: 700 recorded runs (`TestData/Alignment/mummer_cli_oracle.jsonl.gz`; 653 normal, 47 error runs; `-mum` 111, `-mumreference` 202, `-maxmatch` 340; 327 multi-record references, 310 with reverse strand, 126 with `-s`, 156 with several query files; text before the header, CR LF, N / IUPAC / odd characters, empty records): stdout and the deterministic stderr lines **700 / 700 equal**; a further 2 500 runs of seed 77 equal during the port.

## `promer` (A3-9d)

`PromerProgram.Run` is the perl script `promer` (3.07) over its four programs; MCP tool `promer`. Sources: the installed script, `prepro.cc`, `translate.cc` / `translate.hh`, `postpro.cc`, `sw_align.cc` / `sw_align.hh`, `sw_alignscore.hh`, `mgaps.cc`, `show-aligns.cc`, `show-snps.cc` (MUMmer 3.23, Debian source package).

1. **`prepro` (`PromerPrepro`, `MummerTranslate`).** The DNA records (`Read_String`: lower case, anything but a letter or `*` becomes `x`) are translated in the six frames (`Translate_DNA`: the 16 symbol IUPAC code `transdna`, the universal code `universal`, `compdna` for the reverse frames; tables extracted by `scripts/alignment/extract_mummer_promer_tables.py`). An ambiguous codon gives `X` (or `B` / `Z` where the code is unambiguous between two amino acids); a character that is not an IUPAC nucleotide (`e`, `z`, `*`) warns `WARNING: Forcing unrecognized DNA char to N` in a forward frame; in a reverse frame the program reads `compdna [-1]`, the word in front of the array, which is 0 in the installed binary (the character acts as `t`, no warning; measured with `prepro` on `ccc?ccc` for 14 letters; the oracle contains such characters). Every frame is ended by the mask character; a stop is written `J`; a stretch of at most `-m` residues between two stops or a sequence end is masked (`X` in the reference, `O` in the query; a stretch of `X` in the query becomes `O`). The reference output is one record `>allcontigs file` with all frames of all sequences, 60 characters per line, the query output a record `>id.frame` per frame.
2. **`mummer -mumreference -l 6` (`MummerProgram`).** The translations are matched as text (no `-n`: every letter is a letter of the alphabet, the output is lower-cased, so reference `x` never meets query `o`, but a stop `j` meets a stop `j`). Matches are used directly (`MummerProgram.Enumerate`), not through text.
3. **`mgaps -l 20 -s 30 -f 0.11` (`NucmerClusters` + `MummerMgapsText`).** `mgaps` passes the header line of a block without a cluster (the port writes it as the program does; `postpro` ignores such blocks).
4. **`postpro` (`PromerPostpro`).** Reads the clusters, maps a start in the concatenation back to (sequence, frame, position) with `refLen = (len + 1) * 2` and `(len - (i % 3)) / 3 + 1` per frame (so a sequence shorter than 2 nucleotides shifts the coordinates of the following sequences, as in the program), sorts the clusters of a (reference, query) pair with the `std::sort` of libstdc++ (`LibstdcxxSort`), extends them with the routines it shares with `postnuc` (`MummerExtension`: `extendBackward` / `extendForward` over `NucmerSwAlign.AlignEngine` with the BLOSUM 45 / 62 / 80 tables, `GOOD_SCORE` 10 / 8 / 8, gap open -10, extend -1; give-up distance `-b` in amino acids, default 60), and writes the delta file: nucleotide coordinates `transC` of the first / last residue (the last base of the codon, `+-2`), error counts from the translated frames (`1 > MATCH_SCORE` counts the similarity errors, stops count as non-alphabetic), delta values in amino acids. `-x 0` warns and uses BLOSUM 62, another invalid value warns and is ignored; `-b` outside 1 - 10 000 warns and is ignored; with `-d` the cluster file lists the clusters with signed frames and three nucleotides per residue.
5. **`show-coords -r`** (with `-o`) is `MummerShowCoords` (already read PROMER files).

**`show-aligns` / `show-snps` on PROMER delta files.** The coordinates are translated back to amino-acid positions and frames (`frame += (s + 2) % 3`, `s = (s + 2) / 3`), the frames are translated, `show-aligns` prints the three rows reference / match row / query (the match row shows the identical residue, `+` for a positive BLOSUM score, a blank otherwise; `-x` selects the matrix; the score is read from the flat `int [4][26][26]` array like the program, so a stop `*` against a letter reads the neighbouring row), `show-snps` reports amino-acid substitutions (`Norm`: position `c * 3 - (3 - |f|)` on the nucleotide strand, reverse frames by `len - c + 1`). A context that reaches past the end of a translated frame holds the zero byte of the translation and the program prints it with `c_str ()`: the context ends there (a frame 2 / 3 translation is one or two residues shorter than the `length / 3` the program tests against).

**Oracle.** `scripts/alignment/generate_promer_oracle.py`: 320 recorded `promer` runs (`TestData/Alignment/promer_oracle.jsonl.gz`; random proteins back-translated with random codons, copies mutated at the amino-acid level with substitutions / in-frame indels / frame shifts, both strands, several records, N / IUPAC / untranslatable characters, lower case, tiny records; every option family `--mum --mumreference --maxmatch -l -c -g -b -d -m -x --noextend --nooptimize --nodelta -o -p`, `-x 0 / 9`, `-b 0 / 20000`, `-m -2`): the `.delta` / `.cluster` / `.coords` text, the stderr text, and the temporary files `.aaref`, `.aaqry`, `.mgaps` (computed with the sub-programs by hand) **all equal on 320 / 320** (9 of them the aborts: a file without sequence); a further 1 920 runs (seeds 20261201 x 420, 99 x 1 500) equal during the port. `scripts/alignment/generate_promer_show_oracle.py`: PROMER delta files of gene-like inputs and of genome-like contig sets (`promer_show_oracle.jsonl.gz`, 105 cases): `delta-filter` 210, `show-coords` 315 (also `-k`), `show-aligns` 210 (also `-x`), `show-snps` 315 (also `-S`, `-x`), `show-diff` 210, `show-tiling` 234 (also `-R`, `-x`, the `-t -u -p` files) **all equal**; two more seeds (125 and 400 cases, 7 458 runs) equal.
