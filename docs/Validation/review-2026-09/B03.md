## Confirmed fixes

### F1 — SEQ-MW-001: selenocysteine (U) / pyrrolysine (O) ignored in protein MW
- Defect: `CalculateMolecularWeight("MUA")` = 220.2892 (U skipped); Biopython 1.88 `molecular_weight("MUA","protein")` = 370.3271; `"OK"` 146.1876 vs 383.4857.
- Source: Biopython `Bio/Data/IUPACData.py` `protein_weights` (22 entries; U 168.0532, O 255.3134), opened via raw.githubusercontent.com; Expasy ProtParam accepts U/O (WebSearch snippet).
- Fix: added U/O to `AminoAcidWeights`; matches Biopython to 1e-4 (U, O, MUA, OK, GUO 462.4026).
- Tests: `CalculateMolecularWeight_SelenocysteinePyrrolysine_MatchBiopython` (5), `AminoAcidComposition_Pyrrolysine_IsWeighted` (2390.9963); fuzz reference table updated to 22 residues; a fuzz case that asserted 'O' = unknown/zero mass (contradicted by Biopython) removed.

### F2 — SEQ-MW-001: missing double-stranded / circular nucleotide MW
- Defect: no equivalent of Biopython `molecular_weight(double_stranded=, circular=)`.
- Fix: new overload `CalculateNucleotideMolecularWeight(string, bool isDna, bool doubleStranded, bool circular = false)` (circular loses n waters; complement strand via canonical `SequenceExtensions.GetComplementBase`/`GetRnaComplementBase`); old 2-arg method delegates, unchanged results.
- Reference: 9 Biopython 1.88 cases, e.g. AGC DNA ds 1890.2057, circular 931.5942, ds+circ 1854.1751; AGC RNA ds 1972.1755; GGGAAAUUUCCC RNA ds 7750.5810.
- Tests: `CalculateNucleotideMolecularWeight_DoubleStrandedCircular_MatchBiopython` (9), `..._OverloadSingleLinear_EqualsDefault`, `..._DoubleStranded_UnknownSkippedAndEmptyZero`.
- Also: doc typo RNA "AGC" 997.6177 → 997.6077 (Evidence Rec. #3, spec §7.1).

### F3 — SEQ-PI-001: wrong EMBOSS N-terminus pKa (8.6 instead of 7.5)
- Defect: `CalculateIsoelectricPoint("A")` = 6.10; EMBOSS 6.6.0 `iep` = 5.5500. Others (ours→iep): all-20 7.36→6.9681; FLPVLAGLTPSIVPKLVCLLTKKC 9.67→9.5678; LACI_ECOLI 6.88→6.8385; K 9.70→9.15.
- Source: EMBOSS `emboss/data/Epk.dat` and `nucleus/embiep.c` (Amino 7.5; raw.githubusercontent.com mirror); iep 6.6 doc page worked examples only reproduce with 7.5 (LACI 6.8385, IFNA2_HUMAN 5.7240). 8.6 came from an outdated web listing.
- Reference: `iep` binary (apt emboss 6.6.0) run on all test sequences.
- Fix: N-term pKa 7.5. Tests: `..._LacIEcoli_MatchesEmbossDocExample`, `..._TerminiOnly_ReturnsEmbossMidpoint555`, `..._Emboss_MatchesIepBinary` (15), `CalculateNetCharge_Emboss_MatchesIepChargeTable`, `CalculateNetCharge_LacIEcoli_MatchesEmbossDocTable`.
- Behaviour change: default pI values shift (e.g. "A" 6.10→5.55); only external caller is MCP `isoelectric_point` (delegates; MCP tests green).

### F4 — SEQ-PI-001: EMBOSS B/Z ambiguity handling missing
- Defect: "B" → 6.10; iep → 3.7498 ("BBBB" 3.4918, "Z" 3.8497, "ZZZZ" 3.6135).
- Source: `embiep.c` splits B→D/N, Z→E/Q by Dayhoff frequency `(int)(0.5+n·f)`. Fix: same split. Test: `..._Emboss_AmbiguityCodesSplitByDayhoff`.

### F5 — SEQ-PI-001: last-digit misrounding
- Defect: bisection stopped at a 0.01-wide bracket and rounded the midpoint (not always the correctly rounded root). Fix: bisect to 1e-9 on [0,14], round to 2 dp. Covered by the exact-value iep/Biopython tests.

### F6 — SEQ-PI-001: Bjellqvist model labelled "simplification" though implementable
- Fix: `enum PkaScale { Emboss, Bjellqvist }`, `CalculateIsoelectricPoint(string, PkaScale)` with Biopython side-chain pKs + N-terminal (A/M/S/P/T/V/E) and C-terminal (D/E) residue-specific pKs; 1-arg overload remains EMBOSS. New public `CalculateNetCharge(string, double pH, PkaScale = Emboss)`.
- Reference: Biopython 1.88 `IsoelectricPoint` — all-20 6.78 (6.784552; seqinr doc 6.78454), INGAR 9.75, PETER 4.53, FLPV… 9.39, LACI 6.39, AKD 6.13, PKD 6.51; out-of-window roots checked vs exact root of Biopython `charge_at_pH` (brentq): MAEGEITTFT 3.79, DDDD 3.52, RRRRRRRR 12.85; charges within 5e-7.
- Tests: `..._Bjellqvist_MatchesBiopython` (12), `..._Bjellqvist_LacIEcoli_MatchesBiopython`, `..._Bjellqvist_ExtremeRoots_AreExact`, `..._Bjellqvist_DependsOnTerminalResidues`, `CalculateNetCharge_Bjellqvist_MatchesBiopython`. Fuzz/property oracles updated to 7.5 + B/Z split.

## Simplifications kept (with reason) / LIMITATIONS proposals

- SEQ-STATS-001 (convention, not simplification): "`CalculateNucleotideComposition.GcContent` counts only A/C/G/T/U (S/W ambiguity codes excluded); use `CalculateGcFraction(GcAmbiguityMode)` for Biopython `gc_fraction` parity. `CalculateAminoAcidComposition` ratios use the count of letter residues as denominator (non-letter `*`/`-` excluded), unlike Biopython/EMBOSS `len(seq)`."
- SEQ-MW-001: "average masses only (no monoisotopic); ambiguous residues/nucleotides (B/Z/X/J/N…) are skipped rather than rejected (Biopython raises ValueError); circular peptides not supported."
- SEQ-PI-001: "pI search window is pH [0,14] (EMBOSS iep uses [1,14] and reports no pI without a sign change; Biopython uses [4.05,12] and clamps). EMBOSS iep options -disulphides, -lysinemodified, -notermini and custom -pkdata are not exposed. Henderson–Hasselbalch model, no electrostatic coupling, no PTMs."
