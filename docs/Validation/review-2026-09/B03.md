## Simplifications kept (with reason) / LIMITATIONS proposals

- SEQ-STATS-001 (convention, not simplification): "`CalculateNucleotideComposition.GcContent` counts only A/C/G/T/U (S/W ambiguity codes excluded); use `CalculateGcFraction(GcAmbiguityMode)` for Biopython `gc_fraction` parity. `CalculateAminoAcidComposition` ratios use the count of letter residues as denominator (non-letter `*`/`-` excluded), unlike Biopython/EMBOSS `len(seq)`."
- SEQ-MW-001: "average masses only (no monoisotopic); ambiguous residues/nucleotides (B/Z/X/J/N…) are skipped rather than rejected (Biopython raises ValueError); circular peptides not supported."
- SEQ-PI-001: "pI search window is pH [0,14] (EMBOSS iep uses [1,14] and reports no pI without a sign change; Biopython uses [4.05,12] and clamps). EMBOSS iep options -disulphides, -lysinemodified, -notermini and custom -pkdata are not exposed. Henderson–Hasselbalch model, no electrostatic coupling, no PTMs."
- SEQ-HYDRO-001 (documented in algorithm doc §5.4, no LIMITATIONS entry proposed): even window with edge 1 returns plain mean (Biopython double-counts centre; ProtScale accepts odd windows only); unknown residues count 0 / are skipped in GRAVY (Biopython raises); ProtScale exponential weighting and scale normalisation not implemented — no reference formula/implementation reachable (ExPASy blocked).

- SEQ-THERMO/TM-001: "SequenceStatistics NN Tm: monovalent salt method 5 only (no Mg²⁺/dNTP); self-complementarity must be stated by caller (Biopython convention); inosine removed rather than rejected; outputs rounded (ΔH/ΔS/ΔG 2 dp, Tm 1 dp). Basic Tm with `useWallaceRule:false` below 14 nt applies the GC formula outside its published domain (not clamped)."

- SEQ-DINUC-001: none kept. Documented conventions (doc §5.4): non-alphabet symbols excluded from all denominators (seqinr; compseq keeps "Other"); only observed dinucleotides are keys; ρ normalises by in-alphabet dinucleotide count, not G-G&F N. Doc error corrected (said count/(N−1)).

- SEQ-SECSTRUCT-001: "Chou–Fasman assignment implements the standard rule set (Chen 2006 + 1978 turn rule); 1978 graded former/breaker classes (Hα/hα/Iα/bα/Bα) with fractional counting and N/C-cap boundary preferences not implemented; Q3 ≈ 50–60 %."
