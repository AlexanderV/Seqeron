## What this is about

`src/Seqeron/Algorithms/Seqeron.Genomics.MolTools/Resources/rebase_enzymes.tsv` (754 enzyme rows,
generated by `scripts/rebase/generate_rebase_enzymes.py`) has eight columns:

- **Columns 1–6** — name, recognition site, cut offsets — come from **Biopython 1.88**
  (`Bio/Restriction/Restriction_Dictionary.py`, REBASE emboss 404) under the Biopython License
  Agreement, which permits redistribution provided the copyright and permission notices appear. They do,
  in the file's own header. **Nothing about these columns is in question.**
- **Columns 7–8** — `Organism` (746 non-empty) and `MethylationField` (282 non-empty) — come from
  **REBASE `allenz.104`**, whose header reads `Copyright (c) Dr. Richard J. Roberts, 2021. All rights
  reserved.`, reaching this repository through the Bioconductor package `crisprBase`
  (`crisprVerse/crisprBase`, package licence MIT). Provenance, sha256 pins and the verbatim header are in
  `docs/Evidence/B08-Source-Provenance.md` §3a and §9.

Seqeron is MIT-licensed, so shipping those two columns effectively re-licenses that slice of REBASE under
MIT. The practical question is narrow: **may 746 organism strings and 282 methylation-site strings be
redistributed inside an MIT-licensed library?** US law would likely treat them as uncopyrightable facts
(*Feist*), and `crisprBase` already redistributes them under MIT — but the EU's sui generis database right
is a separate matter, so written permission is worth more than an inference. This file is not legal advice.
