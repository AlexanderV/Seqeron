## Confirmed fixes

### F1 — META-CLASS-001: TaxonomyTree accepted parent cycles → infinite loop
- **Defect:** constructor validated single root + existing parents but not acyclicity. Repro: `new TaxonomyTree({(1,r,root,1),(2,a,x,3),(3,b,x,2)})` accepted; `IsAncestorOf(1,2)` / `GetPathToRoot` / `Lca` never return (hang under 10 s timeout) → `ClassifyReads` and MCP `classify_reads` hang on any hit to taxon 2/3.
- **Source opened:** Kraken 1 `src/{classify.cpp,krakenutil.cpp,krakendb.cpp,set_lcas.cpp}`, Kraken 2 `src/classify.cc` + `docs/MANUAL.markdown` (raw.githubusercontent.com). `lca`/`resolve_tree` walk `while (node > 0)` to the root — a rooted taxonomy must be acyclic.
- **Reference cross-check:** literal Python port of Kraken 1 `lca`/`resolve_tree`/`set_lcas` + scan loop + manual C/Q; 400 random taxonomies/DBs × 2000 reads (k 3–5, RC, N, lowercase) → C# identical in taxon, RTL, C, Q and DB contents (before and after fix). Kraken 2 manual confidence example `562:13 561:4 A:31 0:1 562:3` → taxon 562, RTL 20, C=16, Q=21.
- **Fix:** private `EnsureEveryNodeReachesRoot` (O(n) walk) in constructor → `ArgumentException` on cycle.
- **Tests:** `TaxonomyTree_Construction_RejectsParentCycle` (2-cycle, 3-cycle with tail; 500-deep chain still accepted), `ClassifyReads_Kraken2ManualConfidenceExample`.

### F2 — META-CLASS-001 (found in META-PROF-001 review): NCBI `superkingdom` rank not mapped to `Kingdom`
- **Defect:** `ExtractRankLineage` mapped only `kingdom`/`domain`. Repro: taxonomy Bacteria(rank `superkingdom`)→…→species; `ClassifyReads` gives `Kingdom = ""`, so `GenerateTaxonomicProfile` counts every bacterial read as unclassified.
- **Source opened:** kraken2 `src/reports.cc` (raw.githubusercontent.com) — `superkingdom` and `domain` both → report code D, `kingdom` → K.
- **Fix:** `superkingdom` added to the D-level mapping; XML doc states the Kingdom slot is the D-level taxon (root-ward write wins over a `kingdom` node), `kingdom` used only when no D-level node exists.
- **Tests:** `ClassifyReads_SuperkingdomAndDomainRanks_FillKingdom` (superkingdom→Bacteria, domain Eukaryota over kingdom Fungi, kingdom-only→Fungi, profile ClassifiedReads = 1).

### F3 — META-ALPHA-001: Chao1 Int32 overflow
- **Defect:** `(double)(f1 * f1) / (2 * f2)` and `(double)(f1 * (f1 - 1)) / 2` evaluated in `int`; f1² wraps for f1 > 46340. Repro: 50 000 singletons + 3 doubletons + one count 10 → negative Chao1 (50000² → −1794967296).
- **Source opened:** scikit-bio `skbio/diversity/alpha/_chao1.py` (raw.githubusercontent.com main + installed 0.7.4); Chao 1987 bias-corrected form via mothur/EstimateS WebSearch snippet.
- **Reference:** skbio `chao1(bias_corrected=False)` → 416716670.6666667 (above input); 1250025001 (50 000 singletons + one 10, f2 = 0).
- **Fix:** arithmetic in double. Branch logic already equals skbio `chao1(bias_corrected=False)` (classic f1²/(2f2) when f1,f2>0, bias-corrected otherwise) — now declared in XML doc.
- **Tests:** M23 `CalculateAlphaDiversity_ManySingletons_Chao1DoesNotOverflow`; M24 `CalculateAlphaDiversity_CountVector_MatchesScikitBio` on {5,3,2,1,1,1,4}: shannon 1.7582428597165525, dominance 0.19723183391003463, inv_simpson 5.070175438596491, pielou_e 0.9035580910917864, S_obs 7, chao1 11.5.
- Notes (declared, unchanged): Pielou = 0 for S ≤ 1 (skbio NaN); +∞ abundances → NaN (no validation); a tiny positive abundance (e.g. 1e-12) passes the integer test as count 0 while counted as observed.

## Simplifications kept (with reason) / LIMITATIONS proposals

- **META-PROF-001** (declared in XML doc + algorithm doc). Proposed LIMITATIONS.md text: *META-PROF-001: taxa are aggregated by name within each rank, so same-rank homonyms (e.g. genus* Bacillus*, bacterial vs stick insect) are merged; class/order/family are not profiled; reads resolved only to higher ranks are not redistributed (no Bracken re-estimation), so lower-rank abundance maps may sum to < 1.*
- **META-ALPHA-001** proposed LIMITATIONS.md text: *Chao1Estimate is the classic Chao (1984) estimator with Chao (1987) bias-corrected fallback when f2 = 0 (= scikit-bio `chao1(bias_corrected=False)`); for non-integer (relative) abundances singletons/doubletons are undefined and Chao1Estimate = S_obs (no unseen-richness correction). Supply raw integer counts for a meaningful Chao1.*
