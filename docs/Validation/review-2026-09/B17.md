- **Source opened:** Kraken 1 `src/{classify.cpp,krakenutil.cpp,krakendb.cpp,set_lcas.cpp}`, Kraken 2 `src/classify.cc` + `docs/MANUAL.markdown` (raw.githubusercontent.com). `lca`/`resolve_tree` walk `while (node > 0)` to the root — a rooted taxonomy must be acyclic.
- **Reference cross-check:** literal Python port of Kraken 1 `lca`/`resolve_tree`/`set_lcas` + scan loop + manual C/Q; 400 random taxonomies/DBs × 2000 reads (k 3–5, RC, N, lowercase) → C# identical in taxon, RTL, C, Q and DB contents (before and after fix). Kraken 2 manual confidence example `562:13 561:4 A:31 0:1 562:3` → taxon 562, RTL 20, C=16, Q=21.
- **Fix:** private `EnsureEveryNodeReachesRoot` (O(n) walk) in constructor → `ArgumentException` on cycle.
- **Tests:** `TaxonomyTree_Construction_RejectsParentCycle` (2-cycle, 3-cycle with tail; 500-deep chain still accepted), `ClassifyReads_Kraken2ManualConfidenceExample`.
