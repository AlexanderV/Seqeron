# TEMPORARY hand-off package A2-19c-last (for the user's Mac)

**What mafft 7.505 does with LAST** (read from `core/pairlocalalign.c`, `core/mafft.tmpl`; nothing was run from the downloaded source): `--lastpair` = `distance=last`, `--lastmultipair` = `distance=lastmulti` (the script stops with "Specify --addfragments too" without a fragment option). `pairlocalalign -r` (all pairs, `calllast_once`) writes `_db` / `_q` (FASTA with the sequence numbers as names), a scoring matrix `_scoringmatrixforlast` made of `n_dis` (nucleotides only: "Not yet supported" for amino acids), calls `lastdb _db _db` and `lastal -v -m <max(10, nd*lastm=3)> -e 5000 -f 0 -s 1 -p _scoringmatrixforlast -a <-penalty> -b <-penalty_ex> _db _q > _lastres`; `readlastresx` reads the `-f 0` (TAB) lines `score name1 start1 alnSize1 strand1 seqSize1 name2 start2 alnSize2 strand2 seqSize2 blocks`, `block2reg` turns the blocks (`len,gap1:gap2,len ...`) into `Reg` lists, the score of the first alignment of a pair is the pair score (`score += penalty` for further ones), the others become `hat3` blocks. `pairlocalalign -R` (`--lastmultipair` with fragments, `lastcallthread`) makes `_db<k>d` / `_q<k>` for every query. `addsingle` then reads `hat2` / `hat3` as for `--6mermultipair`.

**What the package does.** For each set of `inputs/sets.tsv` (generated by `make_inputs.py`, fixed seed): 38 `--lastmultipair` and 146 `--lastpair` sets, 120 DNA sets of 2 - 25 sequences of 60 - 1500 nt (reverse complemented members, lower case, N, identical sequences, very short sequences), 66 sets with `--addfragments` / `--addfull` / `--addlong` / `--addtotop` (the alignment made by the installed mafft, new sequences in `new.fa`), 26 protein sets (the message "Not yet supported"), with option lines (`--retree`, `--maxiterate`, `--treeout --distout`, `--reorder`, `--op --ep`, `--nofft`, `--anysymbol`, `--thread 2`, `--keeplength`, `--mapout` ...): `mafft <options> in.fa` WITHOUT `--quiet`, twice; the return code, standard output, standard error, the files, and **every call of `lastdb` / `lastal`** (arguments, working directory, the files mafft wrote for it, standard output = the raw LAST output, standard error, return code; through `last-log`, a logging wrapper that runs the real program). Only equal repetitions count as deterministic.
LAST: the image builds the sources of LAST 1256, 1250, 1282, 1411, 1542 (gitlab.com/mcfrith/last, `make install`), tries the Debian package `last-align` too, times the real `lastal` call of mafft on `smoke_db.fa` / `smoke_q.fa` for each and selects the first that answers within 90 s (`out/last-candidates.txt`, `out/versions.txt` name it with the sha256 of `lastal`).
