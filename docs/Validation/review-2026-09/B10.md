### F6 — ASSEMBLY-DBG-001: duplicate/overlapping reads gave chimeric contigs
- Old model: one Eulerian walk per component over every k-mer *occurrence*, so each read copy added a parallel edge and the walk spelled k-mers absent from the input. Repro (k=3/4/3): `ACGT,ACGT` → `ACGGTT` (oracle `ACGT`); `ATGGCGT,GGCGTGCA` → `ATGGCGGTTGCA` (oracle `ATGGCGTGCA`); `AAABBB,AABBBC` → `AAABBBBBBC` (oracle `AAA,AABB,BBB,BBC`).
- Sources: Rosalind BA3K/BA3M (Compeau & Pevzner ch.3: contigs = maximal non-branching paths, isolated cycles included); Zerbino & Birney 2008 Velvet paper (PDF opened: redundancy does not add nodes; RC recorded with each k-mer; merge rule). Two independent Python oracles (BA3M verbatim; Velvet merge) agree on 13 inputs and reproduce both Rosalind samples (code in Evidence).
- Fix: distinct k-mers (Core `SequenceExtensions.CountKmersSpan`, case-insensitive, upper-case output); new public `FindMaximalNonBranchingPaths`; opt-in `AssembleDeBruijn(reads, params, includeReverseComplement)` (Velvet double strand; each contig/RC pair reported once as the smaller string). `BuildDeBruijnGraph` unchanged (textbook multigraph, BA3K reproduced). MCP `assemble_de_bruijn` gains optional `includeReverseComplement`.
- Tests: `AssembleDeBruijn_OverlappingReads_AssembleIntoGenome`, `_DuplicateReads_DoNotDoubleTheGenome`, `_SharedKmersAcrossReads_CountedOnce`, `_IsolatedCycle_IsEmitted`, `_LoopThroughBranchNode_EmittedAsPath`, `_ALongRepeat_SplitsAtRepeatBranches`, `_ToEveryK4_SplitsAtTurnRepeat`, `_ToEveryK3_ContigsPartitionTheKmerSet`, `_MixedCaseReads_JoinCaseInsensitively`, `_ReadShorterThanK_IsSkipped`, `_ReadOrder_DoesNotChangeContigs`, `_ReverseComplementOption_*` (2), `FindMaximalNonBranchingPaths_Ba3mSample`, `_Ba3kSample_OverKmerMultigraph`, `_EmptyGraph_NoPaths`, `_NullGraph_Throws`; fuzz `AssembleDeBruijn_RandomReads_ContigsPartitionDistinctKmers` (600 trials).
