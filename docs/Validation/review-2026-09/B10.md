## Confirmed fixes

### F1 — ASSEMBLY-OLC-001: layout ignored in-degree / cycles
- Repro: 6-mers of GTACGTACGAT (l=4) → 5 contigs; reference GREEDY (Langmead greedy_scs, raw.githubusercontent.com/kywertheim/Greedy_shortest_common_superstring/main/main.py; Blum et al. 1994 via snippets) → `GTACGTACGAT`. Duplicate reads formed an unmerged 2-cycle; `TTTTCATGCA,GGGGGATGCA,CATGCAAAAA,TGCACCCCCC` → 3 contigs vs reference `TTTTCATGCAAAAA`,`GGGGGATGCACCCCCC`.
- Fix: edge-GREEDY (sort overlaps desc, take edge iff head/tail free and no cycle; union-find). Tests: `AssembleOLC_GtacgtacgatSixMers_GreedyRejectsCycle_ReconstructsGenome`, `AssembleOLC_TakenHead_TailUsesNextBestSuccessor`, `AssembleOLC_DuplicateReads_AssembleIntoOneContig`.
### F2 — ASSEMBLY-OLC-001: contained reads became spurious contigs
- Source: Myers 2005 (contained reads removed from string graph; snippet). Fix: containment removal before layout, re-placed for consensus. Test: `AssembleOLC_ContainedRead_DoesNotProduceExtraContig`.
### F3 — ASSEMBLY-OLC-001: consensus kept first read's bases
- Repro `ACGTTGCTAC,TGCAACGGAT,GCAACGGATT` (l=5,id=0.8) → `ACGTTGCTACGGATT`; reference (Biopython 1.79 `dumb_consensus`, raw.githubusercontent.com/biopython/biopython/biopython-179/Bio/Align/AlignInfo.py) → `ACGTTGCAACGGATT`. Fix: layout → canonical `ComputeConsensus`. Tests: `AssembleOLC_MismatchInOverlap_ResolvedByMajorityVote`, `AssembleOLC_TwoReadTieInOverlap_EmitsAmbiguitySymbol`.
### F4 — ASSEMBLY-OLC-001: zero-length overlaps accepted
- `minOverlap ≤ 0` chained all reads. Now `ArgumentOutOfRangeException` for minOverlap<1 or minIdentity∉[0,1]/NaN in FindOverlap, FindAllOverlaps×2, AssembleOLC. Test: `OverlapThresholds_OutOfRange_Throw` (5 cases).
### F5 — ASSEMBLY-OLC-001: documented defaults ignored
- `parameters ?? new AssemblyParameters()` zero-initialised the record struct. Added `SequenceAssembler.DefaultParameters` (20, 0.9, 31, 100). Test: `AssembleOLC_NoParameters_UsesDocumentedDefaults`.
