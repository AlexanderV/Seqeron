## Confirmed fixes

### F1 — TRANS-CODON-001: IUPAC-ambiguous codons always translated to 'X'
- Defect: `GeneticCode.Standard.Translate("GCN")` → 'X' (Biopython 'A'); TAR → 'X' (Biopython '*'); RAY → 'X' ('B'), SAR → 'X' ('Z'), MTH → 'X' ('J'); table 2 AGR → 'X' ('*'). `IsStartCodon`/`IsStopCodon` rejected ambiguous codons. `Translator.Translate("AUGNNNGCNUAA")` → "MXX*" (Biopython "MXA*").
- Source: Biopython `Bio/Data/CodonTable.py` + `Bio.Seq._translate_str` (raw.githubusercontent master, = installed 1.88).
- Cross-check: exhaustive 15³ = 3375 IUPAC codons × 27 tables (translation, start, stop) — 100 % match to Biopython 1.88.
- Fix: expand the ambiguous codon; all-stop → '*', stop+AA mix → 'X', single AA → AA, else B/Z/J if the set is {D,N}/{E,Q}/{I,L}, else 'X'; start/stop only if all expansions are.
- Tests: `Translate_AllIupacCodons_AllTables_MatchBiopython`, `IsStartStopCodon_AllIupacCodons_AllTables_MatchBiopython`, `Translate_AmbiguousCodons_ResolvedAsBiopython` (+ embedded TSV `TestData/GeneticCode/biopython_ambiguous_codons.tsv`); test bent to old code (`Translate_AmbiguousIupacCodon_ProducesX`, "MXX*") corrected to sourced "MXA*".

### F2 — TRANS-CODON-001: only 4 of 27 NCBI translation tables
- Defect: only tables 1, 2, 3, 11 existed (declared "simplified").
- Source: NCBI gc.prt Version 4.6 (raw.githubusercontent ncbi/ncbi-cxx-toolkit-public `src/objects/seqfeat/gc.prt`), parsed and confirmed identical to Biopython's 27 tables.
- Fix: all tables 1–6, 9–16, 21–33 built from the NCBI strings; new `GeneticCode.SupportedTableNumbers`; dual-coding stops in tables 27/28/31 translate to the AA while `IsStopCodon` is true (as Biopython).
- Tests: `SupportedTableNumbers_MatchNcbiGcPrt_V46`, `DualCodingStops_Tables27_28_31_TranslateToAminoAcidAndAreStops`; `TranslationFuzzTests` table lists updated.
