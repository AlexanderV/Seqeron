## Confirmed fixes

### F1 — PARSE-FASTA-001: `ToFasta`/`WriteFile` with `lineWidth: 0` loops forever
- Repro: `FastaParser.ToFasta(entries, 0)` never returns (wrap step 0); negative width threw an unrelated AsSpan error.
- Source: Biopython `FastaWriter` ("Use zero (or None) for no line wrapping"). Reference: Biopython `wrap=0` → `">s1 demo\nACGTACGTAC\n"`; `wrap=-1` → ValueError.
- Fix: 0 = unwrapped; negative → `ArgumentOutOfRangeException`. Tests `ToFasta_LineWidthZero_WritesUnwrappedSequence`, `ToFasta_NegativeLineWidth_ThrowsArgumentOutOfRange`.

### F2 — PARSE-FASTA-001: `;` comment lines parsed as sequence (threw ArgumentException)
- Repro: `">s1\n;c\nACGT"`.
- Source: Pearson fasta36 `nmgetlib.c` `agetlib` skips `;` lines; Biopython `fasta-pearson`. Reference: `">s1 desc\n;comment line\nACGT\n;another\nGGCC\n>s2\n;c\nTTAA\n"` → [(s1, ACGTGGCC), (s2, TTAA)]; leading `;` lines before first `>` ignored.
- Fix: `;` lines ignored on all parse paths (sync/async/alphabet). Tests `Parse_SemicolonCommentLines_AreIgnored`, `Parse_LeadingSemicolonComments_AreIgnored`, `ParseFileAsync_And_AlphabetOverload_IgnoreCommentLines`.

### F3 — PARSE-FASTA-001: id split only on space/tab
- Source/reference: Biopython `title.split(None,1)[0]`: `>s1\x0bdesc` → `s1`, `>s1\xa0desc x` → `s1` (Seqeron returned whole title).
- Fix: split at first `char.IsWhiteSpace`. Test `Parse_HeaderSplitOnAnyWhitespace_MatchesBiopythonId`.

### F4 — PARSE-FASTA-001: no writer for `FastaRecord` (RNA/protein/IUPAC)
- Added overloads `ToFasta(IEnumerable<FastaRecord>, int)`, `WriteFile(string, IEnumerable<FastaRecord>, int)` (additive). Reference: Biopython wrap=4 on `mwyx/BZJUO*` → `>p1 prot\nMWYX\nBZJU\nO*\n`. Tests `ToFasta_FastaRecords_Protein_WrapsLikeBiopython`, `WriteFile_FastaRecords_WritesToFastaOutput`.
