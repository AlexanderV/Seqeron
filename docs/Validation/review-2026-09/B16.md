### F1 — PHYLO-DIST-001: pair with no comparable sites returned 0 instead of NaN
- Defect: `CalculatePairwiseDistance("----","NNNN", JukesCantor)` = 0 (also `("","")`, matrix `{"AC--","--GT"}`) — non-overlapping sequences looked identical.
- Source: ape `src/dist_dna.c` (`distDNA_*_pairdel`, p = Nd/L, L=0 → NaN; raw.githubusercontent.com/cran/ape); scikit-bio 0.7.4 `pdist`/`jc69`/`k2p`.
- Reference: scikit-bio → nan/nan/nan; code before 0; after NaN. 406 seeded random pairs vs scikit-bio + ape-logic re-implementation: all finite values identical (max |Δ| = 0).
- Fix: `comparableSites == 0` → Hamming 0, p/JC/K80 NaN; XML docs. Tests: `CalculatePairwiseDistance_NoComparableSites_ProportionsNaN_HammingZero`, `CalculatePairwiseDistance_MatchesScikitBio`; fuzz test renamed to `EmptySequences_NoComparableSites_HammingZero_ProportionsNaN`.
- Note: saturation (JC p ≥ 0.75 / K80 log arg ≤ 0) kept as +∞ — references disagree (scikit-bio NaN, ape +Inf at boundary / NaN beyond); documented.
