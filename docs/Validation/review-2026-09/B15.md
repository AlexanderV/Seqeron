## Confirmed fixes

### F1 — DISORDER-PRED-001: non-positive windowSize not rejected
- Defect: `PredictDisorder(seq, windowSize: -1)` threw an opaque range exception from slicing; `windowSize: 0` silently used a 1-residue window. Campen 2008 (PMC2676888, snippets) defines a 21-residue window; w < 1 is undefined.
- Fix: `ArgumentOutOfRangeException.ThrowIfLessThan(windowSize, 1)` in `PredictDisorder` and `PredictDisorderRegions`. Test `PredictDisorder_NonPositiveWindow_Throws` (0, −1, −21).
- Reference cross-check (no numeric change): α-synuclein P37840 per-residue TOP-IDP scores vs independent Python re-implementation match to 1e-12 (e.g. r10 0.5422361, r120 0.6138301); content 102/140, regions [10–43],[47–66],[94–139]. Locked in `PredictDisorder_AlphaSynuclein_MatchesIndependentTopIdpReference`.

### F2 — DISORDER-REGION-001: MobiDB-lite flavour classification was a whole-region simplification
- Defect: `ClassifyRegionFlavorMobiDbLite` applied the MobiDB-lite flavour function to the whole region; MobiDB-lite v3 (`consensus.py:get_region_features`) classifies per residue with a 7-residue mirrored window, smooths each flavour track (`math_morphology(rmax=5)`), merges with PA priority, and emits sub-regions ≥10. Repro: α-synuclein IDR 94–139 → whole-region PA; reference → PA 94–104 + NPE 111–139. G12D12 → NPE vs reference GlycineRich 0–10 + NPE 11–23.
- Source: `raw.githubusercontent.com/BioComputingUP/MobiDB-lite/v3/` (`mdblib/states.py`, `consensus.py`, …) executed verbatim as reference; Necci 2020 (Bioinformatics 36:5533) snippets.
- Fix: new `DisorderPredictor.PredictFlavorSubregionsMobiDbLite(sequence, regions?, lowComplexityMask?)` (verbatim port), `FlavorSubregion` record, `DisorderFlavor.LowComplexity` (appended). Shared private `ClassifyFlavorWindow`; old whole-region method unchanged in behaviour. Cross-check: 400/400 random fixtures identical to reference (seed 20260928, all 8 flavours). Tests FS1–FS8 in `DisorderPredictor_RegionFlavor_Tests`; α-syn regions (10,43),(47,66),(94,139) + mean scores locked in `PredictDisorderRegions_AlphaSynuclein_MatchesIndependentReference`.

### F3 — DISORDER-REGION-001/MORF: PredictMoRFs threw under default LimitationPolicy mode
- Defect: `PredictMoRFs` called `PredictDisorder`, which enforces the DISORDER-REGION-001 guard (Permissive-only), so `PredictMoRFs(any)` threw `SeqeronLimitationException` in Moderate (library default) and Strict although it only uses per-residue scores. Hidden because the test assembly runs Permissive.
- Fix: `PredictMoRFs` calls unguarded `ComputeDisorder(seq,21,0.542,5)` (identical scores). Test `PredictMoRFs_NotBlockedByRegionConfidenceGuard` (Moderate + Strict: 25P+30L+25P → (29,50), 0.275934).
