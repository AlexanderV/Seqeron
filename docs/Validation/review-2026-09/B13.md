## Confirmed fixes
### F1 — MIRNA-SEED-001: FindSimilarMiRnas matched seedless miRNAs
- Defect: mismatch count computed over min(seed lengths) → entry with empty seed (<8 nt) scored 0 mismatches; empty query matched all. Repro `FindSimilarMiRnas(let7a,[CreateMiRna("short","UGA")],0)` returned "short".
- Source: Bartel 2009 (seed = nt 2–8); fix uses CompareSeedRegions (Hamming + length difference), skips empty seeds. Tests: miR-21 vs miR-590-5p = 0 mm, vs let-7a = 5 mm (hand Hamming), thresholds 0/4/5.
### F2 — MIRNA-SEED-001: GroupBySeedFamily grouped all seedless miRNAs as family ""
- Contradicted CompareSeedRegions (empty seed ⇒ no family). Now excluded. Test: {let-7a,b,c}→GAGGUAG, {miR-21-5p, miR-590-5p}→AGCUUAU.
### F3 — MIRNA-SEED-001: seed family comparison was case- and T/U-sensitive
- `gaggtag` ≠ `GAGGUAG`. Source opened: TargetScan 7.0 `targetscan_70.pl` L229–232 (`s/T/U/gi; uc`) (raw.githubusercontent.com/nsoranzo/targetscan). Fix: private NormalizeSeed (upper, T→U) in comparison/grouping. Test: DNA lower-case let-7a vs RNA → 7 matches, same family, one group.
### F4 — MIRNA-SEED-001: GenerateSeedVariants duplicates / dead flag
- Lower-case/DNA input produced the original as a "variant" (`"Gag"`). Input now normalised: 7-nt seed ⇒ 1+3·7 = 22 distinct variants; `includeWobble` documented as no-op (all single substitutions already enumerated); null ⇒ ArgumentNullException (also CreateMiRna/GroupBySeedFamily/FindSimilarMiRnas, previously NRE).
### F5 — MIRNA-TARGET-001: FindTargetSites duplex window taken downstream of the seed match
- Defect: `CreateTargetSite` used `mrna[Start..Start+L-1]`, but the miRNA 3′ end pairs **upstream** of the seed match → wrong Alignment/FreeEnergy/Score/TargetSequence. Repro: let-7a vs `GGGGGCUACCUCAGGGGG` → window `CUACCUCAGGGGG`, seed shown unpaired.
- Sources opened: TargetScan `targetscan_70_context_scores.pl::extractSubseqForAlignment` (utrStart−16..utrEnd), `targetscan_70.pl` (classification unchanged, confirmed correct); Bartel 2009 Fig 1.
- Fix: window `mrna[max(0,p1−L+1)..p1]`, p1 = base opposite nt 1 (N-padding past end). Now `GGGGGCUACCUCA`, `||||||||:   :`, Score 0.97, ΔG −17.96. Tests REG-001..004; property/metamorphic oracles that locked the old window corrected.
### F6 — MIRNA-TARGET-001: AnalyzeTargetContext contradicted Grimson 2007
- Defect: +0.3 bonus for mid-UTR sites (paper: sites away from the centre are more effective), unweighted AU including the site, "near start" = 15 % of length instead of 15 nt.
- Sources: Grimson 2007 (WebSearch snippets); TargetScan `getLocalAU_contribution` + `$MIN_DIST_TO_CDS=15` (opened). Fix: TargetScan inverse-distance-weighted AU excluding site; NearStart = 1-based start < 15; ContextScore 0 if NearStart else 0.5·AU+0.5·EndProximity; out-of-range → zeros. Cross-check: weighted AU fixture = (H10−1)/H10 = 0.6585828478525945 (unweighted 0.9). Tests CTXA-001..007.
### F7 — MIRNA-TARGET-001: CalculateSiteAccessibility was a pair-count heuristic returning 0
- Fix: McCaskill P(site entirely unpaired) via canonical `RnaSecondaryStructure.CalculateRegionUnpairedProbability`, 80-nt centred context (RNAplfold −W 80). ViennaRNA 2.x cross-check (d2 / Seqeron): 0.9770/0.9721, 0.9701/0.9630, 1.3e-4/3.2e-4 (old heuristic: 0,0,0). Tests ACC-001..007; MCP tests `AnalyzeTargetContextTests`, `SiteAccessibilityTests` updated to sourced values.
