### KMER-FREQ-001 — K-mer frequency / spectrum / entropy
- Stage A PASS-with-notes: frequency = count/(L−k+1) (= skbio `kmer_frequencies(overlap=True, relative=True)`); spectrum = count-of-counts over distinct k-mers (Chor et al. 2009 Genome Biol 10:R108 snippet; Jellyfish `histo_main.cc` `++histo[count]`, opened); entropy = −Σp log2 p bits, un-normalised. Doc fixes: k≤0 throws only for non-empty input; complexity O(n·k); "distinct k-mers". Notes: no Jellyfish `-h` cap bin; single-strand (Jellyfish usually `-C`).

Spectrum AACAACAACAACGT k=3 = {1:2, 3:2, 4:1}.
- MCP `kmer_spectrum`, `kmer_frequencies` (AnalysisTools.cs), `kmer_entropy` (SequenceTools.cs) delegate.
