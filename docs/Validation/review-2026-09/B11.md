## Simplifications kept (with reason) / LIMITATIONS proposals
- **ANNOT-GENE-001 (proposal):** "`FindRibosomeBindingSites*` score = motif length / 6 is a motif-complementarity heuristic; it does not model spacer or initiation strength. Published RBS scores need genome-trained weights (Prodigal `train_starts_sd`: log-odds over 28 motif/spacer bins, requiring the full Prodigal gene model and iterative self-training on the input genome) or a thermodynamic model (RBS Calculator, Salis 2009: exact mRNA/16S co-folding plus fitted terms). Use the score only to rank motif length. `PredictGenes` picks the longest ORF (first start) per stop; no RBS- or coding-based start refinement." Reason kept: genome-specific trained model / critically complex. Declared in XML doc of `ScanStrandForShineDalgarno` and `docs/algorithms/Annotation/Gene_Prediction.md` §5.3.
