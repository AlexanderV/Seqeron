### F1 — ANNOT-ORF-001: alternative initiator not translated as Met
- Repro `FindOrfs("GTGAAAAAAAAATAA",1,false)` → `VKKK*`; Biopython `Seq(...).translate(table=11,cds=True)` / getorf `-methionine Y` → `MKKK*`. ### F2 — ANNOT-ORF-001: `requireStartCodon=false` lost leading/stop-less regions
- Repro `FindOrfs("CCCAAATAAGGG",1,false,false)` → only `9,12,G`; getorf `-find 0` → {0,9,PK*; 1,10,PNK; 2,11,QIR; 9,12,G}. Fix: `FindStopToStopOrfsInFrame` mirrors getorf (frame starts open). Test `FindOrfs_NoStartRequired_ReportsLeadingAndTrailingStopToStopRegions`.
### F3 — ANNOT-ORF-001: duplicate sub-ORFs in stop-to-stop mode
- Repro `FindOrfs("TAAATGAAATAA",1,false,false)` emitted [3,12) `MK*` twice; reference {1,7,K*; 2,11,NEI; 3,12,MK*; 7,10,N}. Test `FindOrfs_NoStartRequired_OneRegionPerStopDelimitedSegment`.
