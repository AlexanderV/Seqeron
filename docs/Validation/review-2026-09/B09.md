## Confirmed fixes

### F1 — ALIGN-GLOBAL-001: `ScoringMatrix.GapOpen` ignored; no affine-gap global alignment
- Defect: every `GlobalAlign` overload is linear NW (each gap position = `GapExtend`); `GapOpen` never read, so `BlastDna` (2/−3/−5/−2) could not be applied as BLAST scoring. Repro: `GlobalAlign("ACGTTTTACGT","ACGTACGT",BlastDna)` charges the 3-nt gap as 3×(−2) instead of −5+3×(−2).
- Sources: Gotoh 1982 gap cost w(k)=v+u·k (GapOpen excludes first extension); BLAST+ manual NBK279684 blastn defaults (reward 2, penalty −3, gapopen 5, gapextend 2 — search snippets); Flouri et al. 2015 (bioRxiv 10.1101/031500, snippets + gata-bio/affine-gaps README) for correct border initialisation.
- Reference cross-check: new `GlobalAlignAffine` = Biopython 1.88 `PairwiseAligner(mode='global', open_gap_score=GapOpen+GapExtend)` = parasail 1.3.4 `nw_trace` on 1048 cases (8 schemes), 0 mismatches; every returned alignment re-scores to its score. Gotoh original border gives A/CAC = −9 vs correct −11.
- Fix: `GlobalAlignAffine` (DnaSequence + string overloads), three-state M/X/Y DP with explicit inter-matrix traceback, Flouri border X(i,0)=o+i·e, Y(0,j)=o+j·e, overflow-safe −∞ sentinel. Linear `GlobalAlign` kept (documented as linear-only).
- Tests: `BlastDnaPreset_MatchesNcbiBlastnDefaults`, `Affine_SingleLongGap_ChargedOneOpening_BlastDna` (5), `Affine_ReferenceScores_MatchBiopythonAndParasail` ×4 (−17, −6, 16, −3), `Affine_TwoSeparateEndGaps_EachChargedAnOpening_FlouriInitialization` (A/CAC = −11, `-A-`/`CAC`), `Affine_ZeroGapOpen_EqualsLinearNeedlemanWunsch`, `Affine_EmptyInputs_BorderValues` (""/ACGT = −13), `Affine_DnaSequenceAndStringOverloads_Agree`.

### F2 — ALIGN-LOCAL-001: `GapOpen` ignored; no affine-gap local alignment
- Defect: `LocalAlign` is linear SW only. Repro: `LocalAlign("ACGTACGTAAAAAAACGTACGT","ACGTACGTACGTACGT",HighIdentityDna)` = 74 (6-gap charged 6×(−1)); affine value 64 (−10 + 6×(−1)).
- Sources: Smith & Waterman 1981 (J Mol Biol 147:195), Gotoh 1982 (J Mol Biol 162:705) — WebSearch snippets; parasail `src/sw.c` and Biopython `Bio/Align/_pairwisealigner.c` (raw.githubusercontent.com, opened) for the zero-floored three-state local recurrence.
- Reference cross-check: 3192 cases (1596 linear + 1596 affine, 8 schemes) — scores 100% equal to Biopython 1.88 `mode='local'` and parasail 1.3.4 `sw_trace`; alignments re-score to their score; ungapped strings = `s[Start..End]`. Seqeron end cell (first row-major max) ∈ Biopython co-optimal set in all checked cases.
- Fix: `LocalAlignAffine` (DnaSequence + string); `GlobalAlignAffineCore` and local share `AffineAlignCore(local)`. XML docs on `AlignmentResult` coordinates (0-based inclusive, −1 for empty local) — docs only, no signature change.
- Tests (`SequenceAligner_LocalAlign_Tests` 7→20): `LocalAlignAffine_LongGap_ChargedOneOpening` (64 vs linear 74), `LocalAlignAffine_ReferenceValues_MatchBiopythonAndParasail` (12 @ (7,12)/(0,5); 10 @ (6,10)/(3,7)), `LocalAlignAffine_ZeroGapOpen_EqualsLinearSmithWaterman` (13, `GTT-AC`/`GTTGAC`), `LocalAlignAffine_OpeningCostPreventsBridging` (8), tie/zero-stop/empty/null tests for linear and affine.

### F3 — ALIGN-SEMI-001: `GapOpen` ignored; no affine fitting alignment; spec errors
- Defect: `SemiGlobalAlign` is linear-only. Repro (test `SemiGlobalAlignAffine_LongGap_ChargedOneOpening`): affine 65 vs linear 75. TestSpec NEG claimed the last-row max for no-match input is at j=1 (it is j=0: AAAA/CCCC → `AAAA----`/`----CCCC`, −4); INV-4 was vacuous.
- Sources: parasail README semi-global variant table (raw.githubusercontent.com, opened); Biopython 1.88 `Bio/Align/__init__.py` (end_insertion_score).
- Reference cross-check: linear and new affine scores equal Biopython `PairwiseAligner(mode='global', end_insertion_score=0)` and parasail `sg_dx` on 1628 random/edge + 400 long (≤200 bp) cases; all alignments ∈ Biopython co-optimal set. Discriminator ACGTAA/CCACGT (1,−1,−1) = 2 (overlap aligner would give 4).
- Fix: `SemiGlobalAlignAffine` (DnaSequence + string) via `AffineAlignCore(AlignmentType)` (M(0,j)=0, end at first max of last row); XML docs state variant, reference equivalents, ties; TestSpec/Evidence corrected.
- Tests: `SemiGlobalAlign_ReferenceAlignments_MatchBiopythonAndParasail` ×3 (12 `--GA-TTACA--`/`CCGATTTACAGG`; 2; 1), `SemiGlobalAlignAffine_ReferenceValues_MatchBiopythonAndParasail` ×3 (0; −4; 7), `…LongGap_ChargedOneOpening` (65), `…OpeningCostPreventsGap` (6), `…ZeroGapOpen_EqualsLinear` (12), `…EmptyInputs` (0; −5).

## Duplication removed

- ALIGN-GLOBAL-001: the cancellable overload `GlobalAlign(string,string,scoring,ct,progress)` re-implemented the full NW fill/traceback; all 4 overloads now share `GlobalAlignCore` (same diagonal>up>left tie order, same progress/cancellation points). Pooled-buffer copy path removed. Behaviour change: empty input to the typed cancellable overload now returns the NW all-gap alignment (consistent with the typed non-cancellable overload) instead of `AlignmentResult.Empty`.

- ALIGN-SEMI-001: `SemiGlobalAlignCore` duplicated the NW fill; removed — `GlobalAlignCore` and semi-global both use `LinearAlignCore(…, fitting)`. Byte-identical outputs on 1628 cases.

## Simplifications kept (with reason) / LIMITATIONS proposals

- ALIGN-SEMI-001: only the *fitting* (query-in-reference) semi-global variant is provided; overlap / all-ends-free variants are not implemented. Scope choice, documented in XML + algorithm doc; no LIMITATIONS entry needed.
