## Confirmed fixes
### F1 — RNA-PAIR-001: DNA `T` rejected by `CanPair`/`GetBasePairType`
- Defect: `CanPair('A','T')`/`('G','T')` = false, contradicting the doc's own "T normalised to U" and the MFE engines/`GetComplement`/`MiRnaAnalyzer.CanPair`. Downstream: `CalculatePartitionFunction` ("T treated as U") gave Z(GGGAAAUCCC)=1044.12 vs Z(GGGAAATCCC)=407.70; `PredictStructure("GGGATAAAAATATCCC")` = `(((..........)))` −0.02 vs U-form `((((((....))))))` −6.05.
- Source: ViennaRNA `model.c` (`BP_ENCODING_DEFAULT`), `sequences/alphabet.c` (`vrna_nucleotide_encode`: upper-cases, T≡U, other chars → 0 non-pairing), raw.githubusercontent.com.
- Reference cross-check: ViennaRNA 2.7.2 `md.pair` over alphabet "ACGUTacgutNnXxRYI-." → 40 pairing ordered pairs; ours 24/40 before → 40/40 after. `RNA.fold` identical for T/U forms (−6.10/−6.10 16-mer d0; −2.50/−2.50 10-mer). After fix Z(T)=Z(U) and T-form PredictStructure = U-form.
- Fix: `PairLookup` includes A·T/T·A, G·T/T·G; `FindStemLoops`/`PredictStructure` normalise T→U (output bases now shown as U for DNA input).
- Tests: `RnaSecondaryStructure_CanPair_Tests.cs::CanPair_TruthTable_MatchesViennaRnaDefaultModel`, `::DownstreamPairing_DnaT_SameAsRnaU`, `::CanPair_DnaT_TreatedAsU`; unsourced "T never pairs" locks corrected in `Fuzzing/RnaBasePairFuzzTests.cs`, `Properties/RnaStructureProperties.cs`. TestSpec/Evidence/algorithm doc updated.
### F2 — RNA-DOTBRACKET-001: non-ASCII letters treated as pseudoknot brackets
- Defect: letter families used `char.IsLetter` → `ParseDotBracket("É.é")` = (0,2); `"ÉÉ..éé"` = (0,5),(1,4); `ValidateDotBracket("É...")` = false; `"Σ((..))σ"` gained spurious (0,7).
- Source: ViennaRNA 2.7.2 sdist `structures/structure_pairtable.c` (`vrna_ptable_from_string`: VRNA_BRACKETS_ALPHA pairs chars 65..90 with +32; `extract_pairs` one stack per family, NULL on any unbalanced family).
- Reference cross-check: 6,713 strings vs `RNA.ptable(s, RNA.BRACKETS_ANY)` (random bracket/letter/WUSS mixes, multi-family, 300 `RNA.fold` MFE structures, 506 non-ASCII mixes): 46 mismatches before (all non-ASCII) → 0 after; ASCII outputs byte-identical before/after.
- Fix: ASCII-only letter families; parse/validate unified in private `ScanDotBracket` (mirrors `extract_pairs`).
- Tests: `RnaSecondaryStructure_ParseDotBracket_Tests.cs::ParseDotBracket_NonAsciiLetters_AreUnpaired`, `::ParseDotBracket_LettersMixedWithBrackets_MatchViennaRnaPtable`, `::ValidateDotBracket_LetterFamilies_MatchViennaRnaPtable`, `::ParseDotBracket_MfeDotBracket_RoundTripsToBasePairs`.

MCP `can_pair`/`base_pair_type`/`rna_complement_base` already delegate. `GetComplement` already calls `SequenceExtensions.GetRnaComplementBase`.
