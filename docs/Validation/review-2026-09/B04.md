## Confirmed fixes

### F1 — SEQ-COMPLEX-COMPRESS-001: Lempel–Ziv complexity computed LZ78 phrases, not LZ76
- **Defect:** `CalculateLempelZivComplexity` used the Naereen "set of seen phrases" parse (Ziv–Lempel 1978 incremental parsing), documented as LZ76. Repro: `1001111011000010` → 8 (LZ76 = 6: 1/0/01/1110/1100/0010); `0`×16 → 5 (=2); `1010…`×16 → 7 (=3); `ACGT`×4 → 9 / 1.125 normalized (=5 / 0.625). TestSpec even asserted the wrong 8/2.0. `EstimateCompressionRatio` and MCP tools `compression_ratio`, `complexity_compression_ratio` inherited the error.
- **Sources opened:** antropy 0.2.2 `entropy.py` (`_lz_complexity`, `lziv_complexity` doctests) from PyPI wheel; NeuroKit2 `complexity_lempelziv.py` (raw.githubusercontent); Naereen `lempel_ziv_complexity` 0.2.2 wheel (the LZ78 parse); WebSearch snippets of Lempel & Ziv 1976 example `0001101001000101` (c=6), Estévez-Rams et al. arXiv:1311.0546 (`010011101101100`, C=6), Wikipedia LZ complexity (`1001111011000010`, c=6).
- **Reference cross-check:** brute-force exhaustive-history definition = antropy on 20 000 random strings (0 mismatches); antropy doctests reproduced (6/1.5; `HELLO WORLD!`×4 → 11 / 0.38596001132145313; A..Z → 26 / 1.0); 6 DNA strings + 20 kb DNA (c=2756, norm 0.984423382950957) match antropy to 1e-12. Lead re-checked 6/2/3/5 with an independent Kaspar–Schuster port.
- **Fix:** LZ76 factorization from the Longest-Previous-Factor array (Crochemore & Ilie 2008; prefix-doubling suffix array + Kasai LCP), O(n log² n) — identical values to the Kaspar–Schuster scan (a direct port took 45 s on the 200 kb fuzz case; now ~1 s). Normalization (Zhang 2009, c/(n/log_b n), base ≥ 2) unchanged. n=1 convention (returns 1) documented.
- **Tests:** `SequenceComplexity_EstimateCompressionRatio_Tests.cs` re-sourced M1–M9/C1/C2 + LZ1976, Estévez-Rams, antropy text (2), DNA (6), 20 kb cases; `ComplexityFuzzTests.cs` reference replaced by brute-force definition, homopolymer c=min(n,2); `Seqeron.Mcp.Analysis.Tests/CompressionRatioTests.cs` → 1.5 / 0.625. TestSpec, Evidence (correction header), `docs/algorithms/Complexity/Lempel_Ziv_Complexity.md`, MCP tool docs corrected.
