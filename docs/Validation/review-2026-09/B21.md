### F1 — VARIANT-CALL-001: case-sensitive column comparison in CallVariantsFromAlignment

- Reference cross-check: bcftools norm (pysam 0.24.1) accepts REF `C` vs FASTA `c`; REF=G/ALT=g rejected as "Duplicate alleles".
- Fix: SNP branch compares `char.ToUpperInvariant`; reported alleles preserved as given.
- Tests: `CallVariantsFromAlignment_CaseOnlyDifference_IsNotAVariant`, `CallVariantsFromAlignment_LowercaseSubstitution_ReturnsSnp`.

### F2 — VARIANT-CALL-001: left-alignment verified & locked (doc correction, no code change)
