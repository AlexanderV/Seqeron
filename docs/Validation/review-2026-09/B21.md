## Confirmed fixes

### F1 — VARIANT-CALL-001: case-sensitive column comparison in CallVariantsFromAlignment
- Defect: `CallVariantsFromAlignment("acgt","ACGT")` returned 4 SNPs (expected 0).
- Source: VCFv4.3.tex (samtools/hts-specs, raw GitHub) l.339/350 — REF/ALT bases "A,C,G,T,N (case insensitive)".
- Reference cross-check: bcftools norm (pysam 0.24.1) accepts REF `C` vs FASTA `c`; REF=G/ALT=g rejected as "Duplicate alleles".
- Fix: SNP branch compares `char.ToUpperInvariant`; reported alleles preserved as given.
- Tests: `CallVariantsFromAlignment_CaseOnlyDifference_IsNotAVariant`, `CallVariantsFromAlignment_LowercaseSubstitution_ReturnsSnp`.

### F2 — VARIANT-CALL-001: left-alignment verified & locked (doc correction, no code change)
- Docs claimed CallVariants indels were not left-aligned. 1000 random single-indel cases run through `bcftools norm -f`: 0/1000 changed (traceback diagonal-first tie-break yields leftmost gaps).
- Tests (M18) lock bcftools-normalized positions: ACGTTTTACG→ACGTTTACG del@3; CAGAGAGT→CAGAGT del@1,2; GCACAT→GCACACAT ins@1,1; ATTG→ATTTG ins@1.
- `CallVariantsFromAlignment` reports caller alignment literally (documented).

### F3 — VARIANT-SNP-001: FindSnpsDirect case-sensitive and treated gaps as bases
- Repro: `FindSnpsDirect("acgt","ACGT")` → 4 SNPs; `("AC-TA","ACGTC")` → SNP `-`→G.
- Source: VCFv4.3.tex l.339/350 (bases case-insensitive; `-` not a valid ALT).
- Cross-check: bcftools norm -c e (pysam 0.24.1) rejects REF=C/ALT=c as duplicate alleles; scikit-bio 0.7.4 `DNA("aCGT",lowercase=True).distance(DNA("ACGT"))` = 0.0.
- Fix: FindSnpsDirect delegates to `CallVariantsFromAlignment(...).Where(SNP)`. Tests M7–M9.

### F4 — VARIANT-SNP-001: unequal-length inputs silently truncated
- Repro: `FindSnpsDirect("ATGC","ATGCAAAA")` → 0 SNPs.
- Source: Hamming distance defined only for equal-length strings (PMC5410656, as quoted in Evidence).
- Cross-check: scipy 1.17.1 `spatial.distance.hamming` and scikit-bio 0.7.4 `DNA.mismatches` raise ValueError on unequal length.
- Fix: non-empty unequal-length → `ArgumentException` (null/empty still → empty). MCP `find_snps_direct` now errors on unequal lengths (description text updated; no signature change). Tests M5 + fuzz/legacy/MCP tests updated.

### F5 — VARIANT-SNP-001/CALL-001: ClassifyMutation labelled N-containing SNPs Ti/Tv
- Repro: A→N → Transversion; C→N → Transition.
- Source: transition = purine↔purine (A,G) / pyrimidine↔pyrimidine (C,T); transversion = purine↔pyrimidine (Evidence quotes).
- Cross-check: `bcftools stats` on {A>N, C>T}: SNPs 2, ts 1, tv 0.
- Fix: non-ACGT base → `MutationType.Other`. Test M11; fuzz RefVsAllN updated. CalculateStatistics (uncovered) verified vs bcftools stats: 3 SNPs, Ti/Tv 2.0 (test M10).

Read aligners use affine gaps costlier than mismatches (BWA-MEM B=4,O=6,E=1). Requires a public affine (Gotoh 1982) global aligner." Declared in XML doc + algorithm doc §5.3/5.4.
