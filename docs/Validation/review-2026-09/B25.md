## Confirmed fixes
### F1 — ONCO-CTDNA-001: catastrophic cancellation in P(≥1 mutant molecule) = 1 − e^(−λ)
- Defect: `CtDnaDetectionProbability` / `IsCtDnaDetected` evaluated `1.0 - Math.Exp(-λ)`. λ=1e-12 → 9.999778782798785e-13 (rel. err 2.2e-5); λ=1e-9 → 9.999999717180685e-10; λ=1e-300 → **0** (violates strict monotonicity INV-03).
- Source: Avanzini et al. 2020 / US 11,085,084 closed form p = 1 − e^(−n·d·k) (WebSearch snippet); reiterlab/ctdna reference code (`settings.py`, `detection.py` on raw.githubusercontent.com) confirms 3.3 pg/GE (0.0066 ng diploid).
- Reference: `-numpy.expm1(-λ)` (agrees with 60-digit Decimal): 9.999999999995e-13, 9.999999995e-10, 1e-300. New code within 1 ulp for λ ∈ {1e-12 … 744}.
- Fix: private `PoissonProbabilityAtLeastOne(λ)` — Kahan expm1 identity (1−u)·λ/(−ln u) for λ ≤ ln 2 (Goldberg 1991), direct 1−u above (avoids subnormal-ln error at λ≈744, caught by FsCheck `DetectMRD_MatchesIndependentPanelOracle`).
- Tests: `DetectionProbability_SmallLambda_FullRelativePrecision` (5), `DetectionProbability_SubnormalLambda_ReturnsLambdaNotZero`, `DetectionProbability_LambdaWithSubnormalExp_ReturnsOne`, `IsCtDnaDetected_ThresholdEqualToReturnedProbability_IsDetected`.
