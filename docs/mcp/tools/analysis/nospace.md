# nospace

EMBOSS 6.6.0 nospace: Removes whitespace from a text file, as nospace of EMBOSS 6.6.0.

## Overview

| Property | Value |
|----------|-------|
| **Server** | Analysis |
| **Tool Name** | `nospace` |
| **Method ID** | `EmbossProgramRunner.Run` |
| **Version** | 1.0.0 |
| **Stability** | Stable |

## Description

EMBOSS 6.6.0 nospace: menu all removes all white space, end the trailing white space, excess the leading and trailing white space and the extra blanks (a unique abbreviation of the menu value is accepted). Equals the installed program on 320 runs (every input format of seqret, ranges, the output formats, the messages of the library; byte for byte). B09 WP61, F280.

## Input Schema

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `text` | string | Yes | The text of the file to process. |
| `menu` | string | No | all, end or excess (-menu, default all). |

## Output Schema

| Field | Type | Description |
|-------|------|-------------|
| `text` | string | The standard output of the program: the sequences written to the standard output. |
| `files` | object | The files the program wrote, by name. |
| `messages` | string[] | What the library printed on the error stream (warnings and errors). |

## Errors

| Code | Message |
|------|---------|
| 1001 | The sequence cannot be empty |
| 1001 | The program died: the messages of the library (a value it refuses, an input no reader reads, a sequence of the wrong kind) |
| 1001 | An input on which the reference program never stops or dies by a fault is refused |

## Examples

### Example 1: A run on a small input

**User Prompt:**
> Run nospace on this sequence.

**Expected Tool Call:**
```json
{"tool": "nospace", "arguments": {"text": "  a \t b   c  \n\n x\ty\n"}}
```

**Response:**
```json
{"text": "abc\n\nxy\n", "files": {}, "messages": []}
```

The output is the text the installed program writes.
