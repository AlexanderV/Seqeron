## Input Schema

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `names` | array<string> | Yes | The sequence names (distinct), one per row. |
| `rows` | array<string> | Yes | The aligned rows: letters and '-', equal lengths, no column of gaps only. |
| `methods` | array<string> | No | Library method: proba_pair (default), slow_pair, lalign_id_pair or any combination. |
| `options` | string | No | Further t_coffee flags (library options such as -relax_lib N, -filter_lib T, -matrix NAME, -lalign_n_top N). |
| `lineLength` | integer | No | The line length of the ascii format (50 by default, cut to a multiple of three). (default: 50) |

## Output Schema

| Field | Type | Description |
|-------|------|-------------|
| `alignmentScore` | integer | SCORE= of the alignment, 0 - 100. |
| `sequenceScores` | array<integer> | The score 0 - 100 of every sequence. |
| `columnScores` | array<integer> | The score 0 - 9 of every column (the cons row); -1 = none. |
| `residueScores` | array<array<integer>> | The score 0 - 9 of every residue; -1 for a gap. |
| `scoreAscii` | string | The score_ascii file of t_coffee. |

## Errors

| Code | Message |
|------|---------|
| 1001 | names or rows is null |
| 1002 | rows of different lengths, letters other than A-Z / a-z and "-", a column of gaps only, repeated names |
| 1003 | fewer than two sequences: "You have not provided any method or enough Sequences" |

## Examples

### Example 1: three DNA rows

**Tool Call:**
```json
{
  "tool": "tcoffee_evaluate",
  "arguments": {
    "names": [
      "a",
      "b",
      "c"
    ],
    "rows": [
      "ACGTACGTTAGCTAGCTAGGATCGATCGA-T",
      "ACGTACGATAGCTAGCTA-GATCGATCGATC",
      "ACGTTCGTTAGCTCGCTAGGATCGATCGA-T"
    ]
  }
}
```

**Response:**
```json
{
  "alignmentScore": 97,
  "sequenceScores": [
    97,
    97,
    97
  ],
  "scoreAscii": "T-COFFEE, Version_13.41.0.28bdc39 ...\nSCORE=97\n..."
}
```
