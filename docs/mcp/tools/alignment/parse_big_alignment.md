## Input Schema

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `base64` | string | Yes | The bytes of the file as base64. |
| `format` | string | No | Format: bigbed, bigmaf or bigpsl. (default: bigbed) |

## Output Schema

| Field | Type | Description |
|-------|------|-------------|
| `alignmentsJson` | string | JSON array of the alignments {sequences, coordinates, attrs}. |
| `targetsJson` | string | JSON array of the chromosomes. |
| `declarationJson` | string | JSON {name, comment, fields: [[type, name, comment], ...]} of the autoSQL declaration. |
| `format` | string | bigBed, bigMaf or bigPsl. |
| `count` | integer | The number of alignments. |

## Errors

| Code | Message |
|------|---------|
| 1001 | base64 is empty or not valid base64 |
| 1002 | Unknown binary format (supported: bigbed, bigmaf, bigpsl) |
| 1003 | Biopython refuses the file (not bigBed, truncated, inconsistent counts or coordinates) |
