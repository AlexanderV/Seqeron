## Input Schema

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `alignmentsJson` | array<string> | Yes | The alignments, each a JSON object (target first; for bigmaf all rows of the MAF block). |
| `targetsJson` | string | Yes | The chromosomes in the order of the alignments, as a JSON array of {"id": "chr1", "length": 1000} objects (bigmaf: the first id is reference.chromosome). |
| `format` | string | No | Format: bigbed, bigmaf or bigpsl. (default: bigbed) |
| `bedN` | integer | No | bigbed: number of BED columns, 3 to 12. (default: 12) |
| `compress` | boolean | No | Compress the data blocks with zlib. (default: true) |
| `itemsPerSlot` | integer | No | bigbed: number of items per data block. (default: 512) |
| `blockSize` | integer | No | bigbed: number of items per R-tree / B+ tree node. (default: 256) |
| `extraIndex` | array<string> | No | bigbed: names of extra string columns to index. |
| `declarationJson` | string | No | bigbed: a custom autoSQL declaration as JSON {"name", "comment", "fields": [[type, name, comment], ...]} (the BED columns first); the extra fields are read from attrs.annotations. |
| `cds` | boolean | No | bigpsl: write the CDS feature of the query in NCBI style. (default: false) |
| `fa` | boolean | No | bigpsl: include the query sequence. (default: false) |
| `mask` | string | No | bigpsl: null, 'lower' or 'upper': repeat-masked target residues are counted as repMatch. |
| `wildcard` | integer | No | bigpsl: the code of the wildcard letter counted in nCount (78 = N); null counts nothing, as Biopython's default string 'N' never equals a byte. |

## Output Schema

| Field | Type | Description |
|-------|------|-------------|
| `base64` | string | The bytes of the file, base64. |
| `format` | string | bigBed, bigMaf or bigPsl. |
| `byteLength` | integer | The number of bytes. |
| `count` | integer | The number of alignments written. |

## Errors

| Code | Message |
|------|---------|
| 1001 | alignmentsJson or targetsJson is null / not JSON |
| 1002 | Unknown binary format (supported: bigbed, bigmaf, bigpsl) |
| 1003 | Biopython refuses the alignments (for example bedN outside 3 - 12, a chromStart after chromEnd, a missing annotation field) |

## Examples

### Example 1: one alignment as bigBed

**Tool Call:**
```json
{
  "tool": "write_big_alignment",
  "arguments": {
    "alignmentsJson": [
      "{\"sequences\": [{\"id\": \"chr1\", \"length\": 100, \"parts\": null}, {\"id\": \"read1\", \"length\": 20, \"parts\": null}], \"coordinates\": [[10, 20, 25, 40], [0, 10, 10, 25]], \"attrs\": {\"score\": 500}}"
    ],
    "targetsJson": "[{\"id\": \"chr1\", \"length\": 100}]",
    "format": "bigbed"
  }
}
```

**Response:**
```json
{
  "base64": "6/KJhwQA...",
  "format": "bigBed",
  "byteLength": 0,
  "count": 1
}
```
